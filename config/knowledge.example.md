# 我們的做法（敢背書的事實）

- （範例）台灣室溫對紅酒偏熱，我們一律先冰 15–20 分鐘再上桌。
- （範例）Old Fashioned 我們用大冰磚，融水慢、後段不會太淡。
- （範例）我們的鐵板主食是現點現煎，出餐約 12 分鐘。

# 店裡的事實

- （範例）地址、樓層、最近捷運站、營業時間。
- （範例）座位數、可否包場、有無戶外座位、寵物友善與否。
- （範例）固定活動：週末 DJ、電競賽事轉播、桌遊之夜。

# 我們的立場／偏好（有爭議的題目寫這裡）

- （範例）我們不做過甜的調酒，糖度偏低是刻意的。
- （範例）我們不強迫低消換位，客人慢慢喝沒關係。

# 絕對不要講的

- （範例）任何療效、健康功效、「解酒」相關說法。
- （範例）沒實際確認過的產地、年份、獎項。

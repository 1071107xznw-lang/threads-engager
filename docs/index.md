# Threads Engager

An open-source, **self-hosted** tool for a single Threads account owner to draft, review, and
publish their own content — and to review replies before sending them. Built on the official
Meta Threads API, with mandatory human approval before anything is sent.

- **Source code**: <https://github.com/1071107xznw-lang/threads-engager>
- **[Privacy Policy](privacy-policy)**

## How it works

1. You run the tool on your own computer and connect **your own** Threads account.
2. It drafts posts and replies for you.
3. **You approve each item yourself** in a local dashboard.
4. Only approved items are sent.

There is no hosted service. Your credentials and data stay in a local file on your machine.

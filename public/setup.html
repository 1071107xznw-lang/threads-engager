設定精靈

連上你自己的 Threads 帳號，兩步就能開始用。憑證只存在你這台電腦。
1 前置 ・ 2 連接帳號 ・ 3 品牌設定

你需要先有一個 Meta App

  1. 到 developers.facebook.com 建立 App，加入使用案例「Access the Threads API」，並把自己加為 Threads tester。
  2. 取得 App Secret：App settings → Basic → App secret（32 碼）。
  3. 取得 Access Token：Use cases → Access the Threads API → Customize → User Token Generator → Generate token（短期，1–2 小時，越快用越好）。

回覆別人貼文與站內趨勢需 App 送審上 Live；原生發文在 Development 模式即可用。
